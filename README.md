<h1 align="center"> 🔍 Plagiarism Detector</h1>

 ### 📖 Project Description
 <p>This project tasked us to create a Plagiarism Detector application using Python. The program compares two essays that have been stored as separate text documents and determines if there is plagiarism by analyzing their contents.</p>

 ### 🛠️ Key Features 
 <li> Display and comparison of the two essays.</li>
 <li> Identification of common words in both essays.</li>
 <li> Specific word search feature.</li>
 <li> Plagiarism detector.</li>

  ### 🎯 Learning Objectives
 <li> File Handling. Reading and processing text files to extract and analyze content.</li>
 <li> Data Structures. Using lists, sets, and dictionaries to store and manipulate text data.</li>
 <li> String Manipulation. Preprocessing text by removing punctuation, conversion to lowercase and splitting it into words.</li>
 <li> Loops and Iterations. Iteration over text data to identify common words and phrases.</li>
<li> Input/Output Operations. Allowing users to search for specific words and displaying results.</li>

 ### 🛠️ Setup & Installation
 i. Clone the project repository locally using your desired terminal
 ```sh
      git clone https://github.com/L-nsamba/plagiarism_detector.git
```
ii. Run the python file
```sh
     python3 .\lnsamba@alustudent.com_IL-2.py.py
```
iii. Follow the respective prompts to view the essay contents
```sh
    Enter 'essay1.txt' or 'essay2.txt':
```
iv. Enter desired option
```txt
===========================
 MAIN MENU
===========================

1. Display common words in both essays.
2. Search for specific word.
3. Calculate Plagiarism Percentage.
4. Exit program.
```
